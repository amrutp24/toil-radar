# Security

toil-radar runs locally: it reads git history, optionally calls the GitHub API through your own `gh` login, and writes to a local SQLite file. It doesn't listen on anything or send data anywhere else.

If you find a vulnerability anyway, report it privately via [GitHub security advisories](https://github.com/amrutp24/toil-radar/security/advisories/new) rather than a public issue. Only the latest release gets fixes.
